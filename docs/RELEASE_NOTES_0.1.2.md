# DJI 4G Panel 0.1.2

- 短信列表使用窗口剩余高度；宽屏左右分栏，窄屏可进入详情并返回列表。
- 新增设备工具：模块资料、17 项预设能力查询、白名单 AT 查询和需逐条确认的专家终端。
- 工具任务复用串口互斥与设备上下文校验；结果不确定时不自动重发，命令与响应仅保留在内存。
- 设置页新增重启面板和设备工具入口。
- 发布验收修复单字符输入崩溃、基本拨号/数据模式命令变体漏拦截，以及排队和运行中工具任务取消失效。取消批量任务后不继续执行剩余查询；已经写出的命令仍可能产生效果。
- 写入后遇到意外提示符、数据模式或无法解析的响应，明确报告结果未知；收到 OK 也不宣称配置已生效。

## 下载

Windows 10/11 x64：下载便携 ZIP，解压后运行 `dji4g-panel.exe`。公开包不包含厂商驱动。MSIX 是未签名开发包，需要满足 Windows 安装策略。

## 验证范围

发布前重新运行格式检查、Clippy、工作区测试、驱动结果模拟测试和打包检查；GitHub Actions 对发布提交执行完整构建与包校验。短信布局截图为模拟数据。

本轮没有执行真实模块 AT 写入、短信发送、驱动安装或网络配置变更。不同固件上的查询、专家命令、取消与拔插行为仍需实机确认。未签名程序在全新电脑和安全软件上的兼容性尚未全面验证。朋友电脑的通信问题不因本次发布被认定已解决。
