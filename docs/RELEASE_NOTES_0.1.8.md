# v0.1.8 · Material 3 全界面重构

- 重新组织应用栏、导航、内容表面、分组列表、按钮、页签、分段切换、开关与状态提示。使用 Google 官方 Material Symbols 图标子集；左上角品牌区为纯文字。
- 首次引导合并重复的进入按钮，底栏按内容排版，驱动和电脑代理说明按需展开。
- 概览将网络检查放在页头，关键读数集中显示；修复主题切换可能回到默认小控件的样式路径。
- 短信列表压缩非交互留白，整行保持可点击；表单、冻结确认与草稿替换窗口统一外观。
- 诊断区分模块通路与电脑网络，修复采用逐项方案入口，保留全部原有确认与身份核验。
- 新增纯内存界面导出和 CPU 离屏预览，不需要桌面截图、键鼠控制或打开窗口。

本轮不改变短信发送/删除、网络检查、驱动安装和受控修复的安全边界。已提交不代表送达，结果未知不自动重试。Clash 配置自动修改入口仍未开放。
