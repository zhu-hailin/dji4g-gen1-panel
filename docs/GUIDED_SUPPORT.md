# 连接引导与详细日志

双击“大疆4G面板独立版.exe”，按首页“开始使用模块”显示的结果继续。

1. 插入有效 SIM，用支持数据传输的 USB 线直连电脑。点击顶部“立即刷新”。
2. USB 未识别时，先检查线缆、接口和供电，并查看“诊断”的具体错误。未识别不一定是缺驱动。
3. 已识别但串口或网卡缺驱动时，进入“修复”→“退出面板并安装驱动”。确认后自动退出，再出现 Windows 管理员授权。若还有其他面板实例，请退出其托盘程序。
4. 安装完成后按结果窗口提示操作；要求重启时先重启。重新打开这个独立 EXE，刷新并查看各项检查结果。没有匹配的驱动或安装失败时不要反复重装，先导出日志。
5. 接口正常后检查 SIM、信号、注册和模块公网/DNS。可用后尝试网页或进入“短信”。不确定发送结果的短信不要重复发送。

始终检测、失败或功能不可用：点击右上角“导出详细日志”。底部显示收集进度；完成后点击“打开所在文件夹”，将生成的单个 TXT 文件发给排障人员。收集最多约两分钟，期间可以继续查看界面。失败或权限不足的查询也会记录，不需要先检测成功。

报告包含设备实例与硬件 ID、驱动版本/签名、串口、IP/DNS/路由、安全软件状态、相关 Windows 驱动安装记录、检测阶段和历史安装日志。不会查询短信正文、SIM 号码或口令。报告含本机设备及网络信息，请仅交给排障人员；无需上传整个应用数据目录。

本程序面向 Windows 10/11 x64。不同电脑、硬件和安全软件仍需实际验证；驱动安装必须匹配设备并获得管理员授权。
