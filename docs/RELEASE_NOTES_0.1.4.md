# DJI 4G Panel 0.1.4

- 新增首次连接引导：自动检查模块各项状态，可跳过直接进入并记住选择，设置中可重新打开。提供官方驱动获取/支持入口；本地含驱动版可使用内置驱动，仍须用户确认安装。
- 修复长短信 16 位引用号截断、跨存储混组和分片头被错误去重的问题。
- 删除整条短信时冻结已读取分片，每片在同一串口会话中核验格式、存储位置和内容后删除。部分失败、取消或结果未知即停止，不自动重试。
- 修复设备工具占用时发送编辑器持续等待的问题；拒绝后保留草稿。短信、工具与修复共用通信占用判断，清理期间继续保持忙碌。
- 概览优先展示运营商、信号、上下行和温度，连接检查可折叠；区分检测中、证据过期、主动探测关闭和明确失败。
- 缺 SIM 不再因 AT 查询成功误显示可用；关闭主动探测立即撤销旧公网/DNS成功证明。接口超时不会自动展开驱动安装建议。
- 增加收件短信回复和能力项单独重查；清空工具历史真正移除旧记录。发送进度、已提交、失败和结果未知使用不同标记及文字。

## 下载和验证范围

Windows 10/11 x64。推荐下载便携 ZIP，完整解压后运行 `dji4g-panel.exe`。公开包不附带厂商驱动；MSIX 为未签名开发包。历史 Release 保留。

已提交给模块不代表对方收到；结果未知不能自动重发。删除核验读取可能改变模块已读状态。完整验证记录见 [本轮验收记录](ACCEPTANCE_20260922_MODULE_MANAGEMENT.md)。模拟截图和自动测试不替代真实短信送达、实机删除、USB 重新枚举与新电脑驱动兼容性验收。
