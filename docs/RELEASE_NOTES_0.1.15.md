# v0.1.15

- 概览 SIM 区域和短信页增加话费查询入口：移动、联通、电信生成运营商查询草稿并进入发送确认流程；广电提供官方营业厅余额查询入口。短号使用本地地址编码，国际号码保留原有编码。
- 修正短信完整列表同步：完整读取成功后移除对应存储区已经不存在的旧记录；失败、取消或部分读取保留缓存，其他存储区和发送记录保留。显示最后一次完整读取的存储区、时间及缓存状态；发送成功后立即安排一次空闲刷新。
- 收件箱增加全部、未读、长短信缺片筛选；支持组合搜索、清空搜索、Ctrl+F 和搜索框内 Esc。筛选后不再显示已隐藏短信的详情。
- 设置页增加“检查更新”入口，显示当前版本、检查中、检查失败和无需更新等结果；手动检查与后台检查共用任务门禁。
- 更新图标打开详情，用户点击“下载更新”后开始下载；首次下载与失败重试使用不同文案。不支持原地更新的目录保留提示，重新检查版本后仍禁止重复下载。
- 诊断项显示观测距今时间。迟到快照中的过期结论及时标记“已过期”，保留历史结果、错误原因和证据。
- 设置页补充主动探测、启动行为、日志生效时间和隐私说明。启动项已确认关闭时显示“已关闭”，状态说明移到开关下方，改善窄窗口排布。
- 同步简体中文、繁體中文和 English 文案与便携包使用说明。

验证记录见 [本次迭代记录](https://github.com/zhu-hailin/dji4g-gen1-panel/blob/v0.1.15/docs/UX_ITERATION_20261011.md)。
