# DJI 4G Panel 0.1.1

- 修复设备属性读取：只读取 DJI 相关设备的详细属性，合法空字符串不再导致整轮 USB 检测失败。
- 修复 AT 状态误判：PDP 配置详情解析失败时保留已完成的 AT 通信与蜂窝观测，相关详情显示为未知，并记录具体解析错误。APN 修改仍使用严格校验。
- 离线驱动安装增加实际安装步骤，保留安装前后接口状态；存在其他设备错误时不再直接报告成功。
- 保留首页引导、安装前退出面板和详细日志导出功能。

## 下载和使用

Windows 10/11 x64。便携 ZIP 解压后运行 dji4g-panel.exe；MSIX 为未签名安装包，需要符合 Windows 的签名/安装策略，不代表双击即可安装。公开包不包含厂商驱动，已安装驱动的电脑无需重装。本机含驱动独立版与公开包具有相同应用版本。

## 验证及已知限制

本版本作为正式 Release 发布，但应用二进制尚未代码签名。自动构建会执行格式、静态检查、测试和包校验；这些检查不替代不同电脑、固件和安全软件的实机验收。

用户提供的新版诊断确认 USB、COM6、公网、DNS、默认路由和短信读取可用；PDP 显示修正仍需远端复测。日志中的 hotspot:source_profile_ambiguous 是独立的热点来源匹配问题，本版本未修复。没有修改用户 APN、USB 模式或网络配置，也未自动发送短信。
