# v0.1.8 Material 3 界面验收记录

开发基线：v0.1.7，提交 `7e4a2ac6f9c04b103fb2b14fc9d5781ac06e8fb7`。本轮在独立工作树 `codex/material-panel-018` 实施；原开发目录的未提交修改未改动。版本升级为 0.1.8。

## 实现与边界

- 应用栏、导航抽屉、内容表面、页签、分段切换、按钮、开关、状态卡和表单采用统一 Material 3 视觉。左上角品牌区只有文字。
- 首次引导仅保留一个进入动作，底栏由内容计算高度，窄窗口说明与按钮分行。
- 概览优先显示检查入口与运营商、信号、上下行和温度；主导航保持 56 像素行高，常用动作至少 40 像素高。
- 短信整行点击、模块/归档入口、详情及确认窗口重新排版；未改变冻结发送、分片删除、结果未知不得重试等业务规则。
- 修复主题槽切换导致恢复默认小控件的问题；浅色和系统另一主题槽均应用本产品样式。
- 使用 Google 官方 Material Symbols 的精简静态字体。来源、修改说明和 Apache 2.0 许可保存在 `apps/panel/assets/material/`。中文字体继续使用系统字体，不随包分发。

## 视觉验证方法

`ui_capture --headless` 直接运行实际 egui 页面，在内存中产生纹理和三角网格，再由 `packaging/scripts/render-ui-mesh.py` 用 CPU 合成 PNG。虚拟时间等待页面动画稳定；没有创建原生窗口，没有桌面截图、键鼠控制或抢占焦点。

矩阵：800×600（100%/150%）、1100×760（100%）、1440×1000（100%），并补充 533.333×400 逻辑尺寸对应 800×600 的 150% 物理尺寸。场景包括主页面、短信与确认、工具、引导、缺串口、SIM 未就绪、DNS 失败、主动探测关闭、发送四种结果、部分删除、草稿替换、单项查询和模块检查排队/授权。

README 中的图片是模拟状态离屏预览，不代表真实信号、联网、短信送达或驱动安装结果。CPU 光栅化的抗锯齿与原生 GPU 渲染可能不同。
