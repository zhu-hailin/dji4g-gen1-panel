# DJI 4G Panel 0.1.3

- 实时速率 Y 轴随当前可见一分钟内的上传、下载最大值重新计算，上限为峰值的 108%。不再为了凑整刻度扩大范围，峰值降低并移出窗口后坐标轴自动缩小。
- 统一四段等距刻度，支持 B/s、KB/s、MB/s；零流量和缺测时保持有限坐标，不将缺测当作零流量。
- 接入本轮温度改进：支持 `+QTEMP: 57,51,51` 无名多通道格式及命名传感器格式，显示原始响应和各通道读数，并增加温度趋势。传感器含义由固件定义，不虚构通道名称。
- 保留 0.1.2 的短信自适应布局、设备工具、取消和结果未知处理。

## 下载和验证范围

Windows 10/11 x64，便携 ZIP 解压后运行 `dji4g-panel.exe`。公开包不含厂商驱动；MSIX 为未签名开发包。GitHub 历史 Release 保留。

发布前执行速率范围与旧峰值移出窗口回归测试、温度解析与界面测试、完整工作区测试、静态检查和构建。界面验收使用模拟数据，不代表本轮已验证真实模块温度、短信送达或驱动安装。
