# DJI 4G Panel 0.1.5

- 历史短信读取由 200 提高到最多 1000 个原始存储记录，支持取消和中文进度。实际可读数量取决于模块与 SIM 的存储容量；显示原始、解码和未展示记录数。
- 增加 SIM 卡／模块存储位置选择：确认后读取，随后恢复原位置。列表和单条读取前后核验 SIM 身份，换卡或无法验证时拒绝混入旧记录。取消、超时和串口释放期间保持通信占用。
- 增加默认关闭的本地历史：当前 Windows 用户加密，最多 5000 条、保存 90 天，号码／正文搜索、保存日期筛选、明确确认后导出 TXT 或清空；历史仅供查看，不能删除模块内容。
- 完善新手驱动流程：安装或取消后回到普通权限面板，中文说明成功、需重启、部分失败、无匹配驱动和模块断开。重启要求优先呈现，已有面板运行时也不丢弃安装结果。

Windows 10/11 x64，推荐完整解压便携 ZIP 后运行 `dji4g-panel.exe`。公开包不含厂商驱动；本地含驱动版仍只安装签名、校验和硬件匹配均通过的驱动，不自动安装、不强制绑定未匹配接口。现有本地驱动包不匹配 MI_04。

读取可能改变短信已读状态。已提交给模块不代表对方收到，结果未知不自动重发。本地历史 TXT 导出包含号码和正文，请妥善保管。

自动测试与模拟截图不能代替干净电脑驱动安装、UAC 返回、实机存储区切换恢复、真实短信送达与删除验收。详细证据见 [本轮验收记录](ACCEPTANCE_20260922_BEGINNER_COMPLETION.md)。
