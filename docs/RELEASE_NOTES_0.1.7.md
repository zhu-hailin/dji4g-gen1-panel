# 0.1.7 · 模块网卡检查与逐项修复

- 新增“检查模块网络”，概览、诊断与首次引导使用同一入口。按一次检查保留 USB、网卡、地址/路由、蜂窝、网关、公网和 DNS 证据，显示排队和步骤。
- 后台主动探测关闭时，可确认仅本次联网检查；长期设置不变。后续刷新不会覆盖本轮报告，过期或换设备后需重查。
- 分开解释模块通路与电脑对测试目标的 IPv4/IPv6 出口；正常 Wi-Fi/VPN 不算模块故障。
- 按证据提供 DHCP 更新、后续网卡重启、恢复自动 DNS 的逐项确认入口；操作后只复检一次，不自动重复写入，未知结果诚实保留。
- README 补充小白操作路径，保留官网入口与“AT 命令（高级）”名称。

边界：不切换路由优先级，不自动改代理，不下载未知来源驱动。自动测试和模拟截图不能替代不同电脑的驱动安装、USB 重枚举与真实模块联网验收。公开便携包不附带厂商驱动；本地独立版只打包已有的校验通过资源。Clash 自动配置修改仍未开放。
