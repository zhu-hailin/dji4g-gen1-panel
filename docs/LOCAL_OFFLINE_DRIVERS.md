# 本地离线驱动版

驱动来自本机 Windows 驱动仓库中实际绑定 DJI 一代模块的 oem259.inf、oem261.inf、oem262.inf，通过 PnPUtil 导出，原始文件未修改。Windows 自带的 RNDIS 网卡驱动不另行打包。

## 使用

1. 解压整个压缩包，不要单独移动 EXE。
2. 打开面板，在「修复 → 首次连接检查 → 需要安装驱动？」点击「启动离线驱动安装器」。也可直接运行 `dji4g-driver-setup.exe`。
3. 退出面板（含托盘），在安装窗口确认，然后同意 Windows 管理员权限提示。无需输入命令。
4. 安装器只处理当前连接的 `VID_2CA3&PID_4006` 设备中 Code 28 的缺驱动接口。当前正常的接口会跳过，硬件 ID 不匹配或匹配不唯一时停止，不强制绑定 AT 接口。
5. 若提示重启，先重启。重新打开面板，分别验证 USB、网卡和 AT 通信；PnP 状态正常不等于短信和网络已经可用。新枚举的子接口可能需要再运行一次安装器。

## 校验与范围

安装器内置八个文件的 SHA-256，校验 CAT 签名并锁定文件防止校验后被修改；安装由 Windows PnPUtil 执行。`dji4g-driver-setup.exe --check` 只校验包，不申请管理员权限、不安装驱动。

这套驱动不是针对任意一代模块、任意 USB 配置的通用驱动：此前强制绑定为 AT 的 MI_04 不在串口 INF 自动匹配范围，本安装器会停止而不会照搬该绑定。遇到此情况需要进一步针对具体接口识别和匹配。

完整安装包包含全部程序及驱动资源，安装到当前用户目录，并创建“ 大疆4G面板”和“安装大疆4G驱动”桌面快捷方式。无需另外下载驱动或携带源电脑的目录。

尚未确认厂商驱动再次公开分发的许可，此构建没有上传公开 GitHub Release。面板和安装器 EXE 是未签名开发构建；厂商驱动的签名与应用签名是不同的验证对象。

当前完成导出、文件/签名校验、负向校验和软件构建；未在干净 Windows 10/11 上执行真实安装验收，也未修改本机正常驱动。

## 2026-09-18 安装诊断修订

驱动安装器直接通过 Windows ShellExecuteExW 请求管理员授权，取消原有 PowerShell 提权中转。驱动验证及 PnPUtil 调用仍使用内嵌 PowerShell 脚本，未关闭或绕过安全软件。

真实安装会在程序目录创建独立的 `driver-setup-时间戳-进程号.log`。失败窗口给出日志路径；驱动步骤失败或取消后，完整安装器停止自动打开面板。接口仍异常时返回失败，需要重启时明确提示重启后复查。只读 `--check` 和 `--plan` 不写安装日志、不提权、不改驱动。

此修订解决安装结果误判及诊断信息不可见的问题，不代表卡巴斯基检测已经通过。已有截图显示驱动安装器被终止、文件及快捷方式被回滚，但缺少具体检测名称，因此尚不能确定检测原因或认定误报。仍需在保留防护的情况下核对检测报告并复测；不要通过关闭防护或添加排除项来验收。

本机只读安装计划发现一个无法唯一匹配的缺驱动接口，已拒绝生成安装计划。此离线包不能自动解决该接口。四个模拟场景（正常、匹配缺驱动、不匹配、设备拔出）已通过，但不能据此宣称所有原厂模块开箱可用。
