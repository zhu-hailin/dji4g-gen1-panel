DJI 一代 4G 面板 · v0.1.16 · Windows 开发版

启动：将压缩包完整解压，运行 dji4g-panel.exe，保持 dji4g-helper.exe 和 dji4g-updater.exe 在同一目录。
升级：先通过托盘或设置页完全退出旧程序，再运行新程序。
本构建未签名，仅供开发测试；MSIX 为 unsigned-development-only。便携 ZIP 无需安装 MSIX。

概览：只读状态、实际网速和温度趋势；宽屏左栏为图表与 Windows 网络详情，右栏为设备与 SIM。页头 GitHub 圆形图标打开本项目。
窗口：默认 1100×720，支持调整大小和滚动；窄窗口可通过菜单切换页面。
设置：常规分组可切换浅色、深色、跟随系统及简体中文、繁體中文、English；选择通过配置保存，保存失败会显示原因。
软件更新：设置页显示当前版本和检查结果，点击“检查更新”可立即重试。发现新版本后，通过“查看更新”或概览页更新图标打开详情，点击“下载更新”；校验通过后点击“安装并重启”。
从 0.1.14 升级：旧版在启动时和此后每六小时检查 GitHub 正式 Release。新版本发布后，从托盘完全退出再重开旧程序，可立即重新检查；概览“刷新”用于模块数据，程序更新入口位于 GitHub 图标左侧。
主动探测会使用少量模块流量；日志详细程度在下次启动后生效。启动项开关下方显示实际读取或保存结果。
检查模块网络：在诊断页或首次引导进入。单独核实模块网卡通路，并解释电脑对测试目标选择的出口；Wi-Fi/VPN 本身不算故障。
后台探测关闭时，可仅查看本地信息，也可确认只允许本次公网/DNS 检查；长期设置不变。
按证据提供更新 DHCP、后续重启模块网卡或恢复自动 DNS，每项需单独确认；完成后只读复检一次，失败或结果未知不会自动重复修复。
无线观测：打开侧栏“无线”；查看频段、PCI、EARFCN、Cell ID、带宽、RSRP/RSRQ/RSSI，SINR 保留原始值。
无线曲线按完成的 AT 查询采样，保留 120 次；设备或 SIM 更换后重置。小区变化不直接等同断线。
短信：支持受控操作的 DJI 模块打开页面后自动读取，停留时每 15 秒同步；发送、修复或编辑期间暂停。通用只读模块禁止模块读取、刷新、发送、删除和切换存储，本地历史仍可浏览与导出。读取可能将模块短信标记为已读。
短信列表显示模块中存储的短信，短信日期是运营商原始时间。列表上方另显示最后一次完整读取的存储区和距今时间；同步失败、暂停或记录较旧时显示缓存状态。只有完整读取成功才移除该存储区已不存在的旧记录，读取失败或不完整时保留历史。
筛选与搜索：收件箱可筛选全部、未读、长短信缺片，并按号码或内容搜索；Ctrl+F 聚焦搜索，搜索框内 Esc 清空。清空搜索或切换“全部”可恢复列表。
查询话费：在概览的 SIM 信息区域或短信页点击“查询话费”。移动生成向 10086 发送 YE 的草稿，联通为 10010 / CXYE，电信为 10001 / 102；选择后进入短信草稿，核对后确认发送，运营商回复显示在收件箱。指令和短信能力以所属地区及套餐为准。
广电话费：通过同一菜单打开中国广电官方营业厅，登录后在“个人中心 → 我的账户”查询余额。本版尚未预置未经官方核实的广电短信指令。
新建短信：支持含国家码的完整号码（如 +8613800138000）以及 10086 / 10010 / 10001 三个客服短号。正文最多 70 个 BMP 字符，不支持 Emoji。下一步核对后才能发送。
确认发送：请求成功进入队列后，编辑和确认弹窗立即关闭，短信页显示本次排队、发送中和最终结果。排队或发送期间，新建短信和查询话费的草稿入口暂不可用。新任务显示本次状态，不沿用上条结果。
草稿：发送失败或结果未知时保留，点击“继续草稿”重新核对并确认；编辑窗不会自动弹出。请求未能进入队列时，草稿和编辑窗保留，可查看原因后重试。
“已提交”仅表示模块接受，并不证明收件人收到。此时清除本条草稿，并在空闲时同步一次收件箱。“结果未知”时不要直接重发；程序不自动重发短信。
诊断：查看各项证据与观测距今时间，过期结果保留原结论并标记“已过期”；可刷新检查并导出脱敏报告。日志不包含完整短信号码、正文或 PDU。
修复：执行前查看前提、影响和确认内容。程序不默认重装驱动、重置网络或修改频段锁。

验收范围：自动测试与模拟界面截图不代替实机验证；新无线观测页面尚需不同固件的实际报告确认。
