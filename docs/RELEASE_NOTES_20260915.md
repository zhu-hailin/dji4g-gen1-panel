# 2026-09-15 更新

- 短信发送使用单一受控串口事务，保留具体错误码，区分未提交、已提交和结果未知；不自动重发。
- 重做短信工作区：消息搜索、列表/阅读分栏、独立写信窗口与确认窗口、小屏列表/详情切换。
- 短信页自动同步：进入页面即读取，停留期间每 15 秒更新；发送、修复期间暂停，保留草稿和选中条目。
- 统一紧凑浅色界面：常规 36px 操作按钮，保留概览、短信、诊断、修复、设置导航。
- 概览新增无线观测：频段、小区、EARFCN、PCI、带宽、RSRP/RSRQ/RSSI、SINR 原始值、120 次采样趋势、20 条小区变化记录、摘要复制。
- 提供经过哈希校验的 Windows x64 便携包和未签名开发 MSIX。

用户已确认此前短信修复版可用；未在本次自动化过程中发送真实短信。无线观测使用已有模块报告，尚未完成不同固件实机验收。

本发布为未签名开发版本。截图使用明确标注的模拟数据，不代表实测信号或短信送达。
